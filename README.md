# Music Island Lyrics

一个常驻 macOS 菜单栏的歌词应用：读取 Apple Music 当前曲目，通过歌名、歌手、专辑和时长匹配在线歌词，并在屏幕顶部中央显示同步歌词。

## 功能

- 读取 Music.app 当前歌曲、歌手、专辑、播放状态和进度
- 显示当前歌曲的专辑封面
- 默认布局中刘海右侧仅显示专辑封面
- 悬停展开后支持播放/暂停、下一首和在线音乐搜索
- 搜索歌名、歌手或专辑，并在 Music app 中打开选中的在线歌曲页面
- 优先显示同步 LRC，找不到时间轴时回退到普通歌词
- 从屏幕顶边延伸的刘海一体化岛形界面，不再显示为脱离菜单栏的悬浮卡片
- 收起高度根据当前屏幕菜单栏和刘海安全区动态计算，不侵入普通窗口内容
- 默认显示滚动歌词，悬停时向下展开并显示歌名和歌手
- 同步歌词按 Music 播放位置和 LRC 时间轴切换，长句在本句时段内只滚动一次
- 应用不占用菜单栏图标；右键岛形区域可搜索在线音乐、重新匹配歌词或退出
- 不需要 Apple Music 开发者 Token

## 构建和运行

要求 macOS 14 或更高版本，并安装 Xcode/Swift 工具链。

```sh
cd MusicIslandLyrics
chmod +x build-app.sh
./build-app.sh
open "dist/Music Island Lyrics.app"
```

首次运行并开始播放后，macOS 会询问是否允许本应用控制 Music。请选择允许；如果误点拒绝，可在“系统设置 → 隐私与安全性 → 自动化”中重新开启。

## 数据与限制

- 歌曲元数据仅在本机读取。
- 歌名、歌手、专辑和时长会先发送给 `https://lrclib.net` 用来检索歌词；未命中时，会再用歌名、歌手和专辑请求 `https://api.lrc.cx/lyrics` 作为补充歌词源。
- 在线搜索词会发送给 Apple 的 `https://itunes.apple.com/search`，结果最多显示 6 首歌曲。
- 无 Apple Developer/MusicKit 配置时，在线搜索结果只能在 Music app 中打开，不能保证自动播放或加入“下一首”。
- macOS 没有向第三方开放系统“灵动岛”组件；本应用使用置顶悬浮窗模拟相邻位置和视觉样式。
- 歌词覆盖率取决于在线歌词源的数据，应用不会编造未检索到的歌词。
